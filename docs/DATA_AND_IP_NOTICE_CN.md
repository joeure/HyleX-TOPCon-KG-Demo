# 数据与知识产权说明

`toy-data/` 中的文档、Ontology、实体、关系和证据均为本项目为评审编写的合成内容，
ID 使用 `toy:` 或 `synthetic` 前缀，不代表真实企业、论文、工艺或实验结果。公开
仓库不包含主开发仓库历史、真实文档、提取结果、Ontology、KG、Provider、企业数据
或凭据。

闭源运行镜像仅限比赛评审，禁止反向工程、复制、商用和再分发。运行方自行提供
Provider 配置和 Secret，并对其许可、合规、费用、可用性和数据出境负责；provision
后服务内部只保存加密凭据和非敏感配置摘要。在线 Demo 应只接受公开或合成数据，
评审结束后删除上传文件。
